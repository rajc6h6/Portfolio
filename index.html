Production system Legal-risk AI agent

Contract Intelligence Engine

LangGraph PydanticAI pgvector Docker
What it is

An AI agent that reads contracts, scores risk, and stops itself before making a decision it isn't confident in.

What I built

Structured extraction pipeline using PydanticAI, pgvector hybrid retrieval over 500+ historical clauses, and a risk scorer that triggers interrupt_before at score > 40.

The hard part

Deciding when the agent should stop trusting itself. interrupt_before on a risk score above 40 was the line between a useful tool and a liability.

Why it works

Hallucination rate under 5% — CI blocks any merge that exceeds it. AsyncPostgresSaver means a mid-execution crash loses nothing.

Production system Autonomous CVE auditor

Dependency Drift Sentinel

LangGraph pgvector GitHub Actions
What it is

A GitHub Actions agent that catches vulnerable dependencies before they merge — and keeps re-checking until the vulnerability is actually gone.

What I built

Cyclic LangGraph loop resolving the full transitive dependency tree, cross-referenced against OSV.dev plus a semantic CVE search layer via pgvector.

The hard part

OSV.dev alone misses aliased package names. Layering semantic search over the CVE corpus is what caught the cases the deterministic check didn't.

Why it works

47 CVEs caught across scans. Recursive self-validation: the agent re-checks its own migration suggestions, not just the original tree.

Production system Zero-risk AI rollout

Shadow-Mode AI Deployment Proxy

FastAPI asyncio LLM-as-judge
What it is

Infrastructure that lets a team run a new AI agent against 100% of real production traffic with zero risk to live users.

What I built

asyncio.gather fan-out to legacy + shadow in parallel, three-layer divergence detection (schema → embedding similarity → LLM-as-judge), nightly k-means clustering of failures.

The hard part

Cutting per-request cost from $0.043 to $0.011 via semantic caching — not optimization for its own sake, but what makes continuous shadow testing affordable rather than a pre-launch ritual.

Why it works

Zero latency added to real users. CI gate requires ≥95% agreement before promoting the shadow agent to production.

AI Decision Layer with Slack Integration

LangGraph FastAPI Slack API PydanticAI
THE SITUATION

The client's team was manually reviewing every incoming decision — even the obvious ones. No triage, no prioritisation. High-confidence cases and edge cases landed in the same queue and got the same human time.

WHAT I BUILT

A LangGraph routing layer that classifies each decision by confidence, auto-approves above the threshold, and sends only the uncertain cases to a human via Slack. Full audit trail on every decision, approved or automated.

WHAT THEY GOT

Manual review volume cut significantly — humans now only see edge cases, not rubber stamps. Response time on escalations dropped because the Slack alert arrives with full context already attached, not a raw request.

Client delivery Document intelligence

Document QA with Citations & Analytics

pgvector FastAPI PydanticAI
THE SITUATION

The client's team was wasting hours searching through dense PDFs and word documents for specific clauses. When they tested off-the-shelf AI tools, they hallucinated answers and couldn't point to the exact source paragraph, making them untrustworthy.

WHAT I BUILT

A hybrid-search RAG pipeline using pgvector that strictly grounds answers in the source material. It generates precise, paragraph-level citations for every claim and automatically logs queries that the knowledge base couldn't answer.

WHAT THEY GOT

Immediate, verifiable answers to complex queries without reading full documents. The automated "Content Gap" report surfaced critical blind spots in their documentation that they didn't even know existed.

Lead Classifier & CRM Automation

LangGraph PydanticAI CRM API
THE SITUATION

Sales reps were drowning in inbound leads, spending hours manually qualifying them. High-value prospects were sitting in the same inbox as spam, causing slow response times and lost revenue opportunities.

WHAT I BUILT

A multi-factor scoring engine that evaluates firmographic signals and intent. High-value leads are instantly enriched and pushed to the CRM. Edge cases trigger smart escalation rules for human review, reducing false negatives to near-zero.

WHAT THEY GOT

Sales team now only talks to pre-qualified, highly-enriched leads. Manual triage time dropped to near-zero, and high-value prospects receive immediate outreach, directly increasing close rates.
